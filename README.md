# Dexter

An AI-powered Telegram chatbot focused on **Information Technology**.

Dexter helps users understand programming, web development, databases, networking, cybersecurity, AI, APIs, Git, and other IT topics using simple language.

It can also analyze **images and screenshots**, including code, error messages, and technical diagrams.

## Tech Stack

* Python 3.13
* Flask
* OpenAI API
* GPT-5.4
* PostgreSQL
* Neon
* Telegram Bot API
* Gunicorn
* Render

## Features

* IT-focused AI assistant
* Text-based questions
* Image and screenshot analysis
* Simple explanations
* Telegram webhook

## How It Works

```text
Telegram
   ↓
Flask
   ↓
PostgreSQL + OpenAI
   ↓
Dexter
   ↓
Telegram
```
